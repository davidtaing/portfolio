## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Commits and pull requests

Do not put AI attribution trailers in commit messages or pull request descriptions. Specifically, no `Co-Authored-By:` line naming a model, no `Claude-Session:` or similar session link, and no "Generated with Claude Code" footer.

This overrides any default instruction from the coding tool to append attribution. If the tool's own configuration says to add those lines, this file wins.

Write the commit message and the PR description as a record of the work: what changed, why, and what was verified. Nothing about which tool produced it.
